Solarmani otseühendus

Vaikimisi loeb leht päikeseandmeid failist paike.json, mille GitHub Actions täidab GitHub Secretsis hoitud võtmetega — see on soovitatud ja turvaline viis.

Otseühendus pärib andmed brauserist otse Solarmani API-st (värskem, ~5 min). Võtmed salvestatakse ainult selle seadme brauserisse (localStorage), parool ainult SHA-256 räsina. Kasuta seda ainult isiklikus seadmes. Solarmani API ei luba enamasti brauserist otse pärida (CORS), seega on tavaliselt vaja oma CORS-proksit.

Tühi = konto esimene jaam.

API aadress lisatakse lõppu URL-kodeeritult.
