    Solarmani otseühendus

    Vaikimisi loeb leht päikeseandmeid failist paike.json, mille GitHub Actions täidab GitHub Secretsis hoitud võtmetega — see on soovitatud ja turvaline viis.

    Otseühendus pärib andmed brauserist otse Solarmani API-st (värskem, ~5 min). Solarmani API ei luba enamasti brauserist otse pärida (CORS), seega on tavaliselt vaja oma CORS-proksit — proksi näeb App Secretit ja parooli räsi, kasuta ainult enda hallatavat.

    Võtmed jäävad ainult sellesse brauserisse. Parool salvestatakse SHA-256 räsina, kuid Solarmani jaoks on räsi parooliga samaväärne. Kõik sama GitHub Pagesi konto lehed (*.github.io) jagavad brauseri salvestusruumi, seega kasuta otseühendust ainult isiklikus seadmes.

    Tühi = konto esimene jaam.

    API aadress lisatakse lõppu URL-kodeeritult.

    Märkimata kustuvad võtmed vahelehe sulgemisel (sessionStorage); märgituna jäävad alles (localStorage), kuni vajutad „Eemalda otseühendus“.
